EWP LAB EXTERNAL EXAMINATION

Product Store — Project Overview

Product Store is a responsive multi-page e-commerce website designed for the Engineering Web Programming laboratory external examination, built exclusively with foundational web technologies without third-party framework overhead.

3-Tier Application Architecture

Standard software engineering pattern for client-server web apps
🖥️

Tier 1: Presentation Layer

Implemented with HTML5 for semantics, CSS3 for responsive Grid and Flexbox, and Pure Vanilla JS (ES6+) for interactive rendering.

app.js (146 lines), products.js, cart.js, auth.js
⚙️

Tier 2: Application / Logic Layer

Powered by Node.js and Express.js. Serves static assets via express.static(), handles routing, and exposes REST endpoints.

server.js, Express Router, /api/products
💾

Tier 3: Data Storage Layer

Structured JSON dataset for products and specifications. User sessions and shopping cart items persist seamlessly across pages using HTML5 localStorage.

PRODUCTS JSON, localStorage

Technology Justification: Why Pure Vanilla Web Standards?

Direct syllabus alignment for university examinations

• No React / Angular: Eliminates heavy build pipelines, thousands of node_modules dependencies, and compilation errors during the timed lab exam.

• No TypeScript: Modern Vanilla JavaScript (ES6+) runs directly in all browsers without transpilation overhead.

• Standard JSON: Native parsing via JSON.parse() and JSON.stringify() provides instant performance.
