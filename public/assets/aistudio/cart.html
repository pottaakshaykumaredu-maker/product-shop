🎓 EWP Lab External Examination Handbook

HTML5 + CSS3 + Vanilla JavaScript (ES6+) + Node.js Express

Zero React / Zero Angular: Built with pure web standards to demonstrate core DOM manipulation, event handling, and localStorage without framework baggage.

3-Tier Architecture

Client Tier: HTML5/CSS3/Vanilla JS
App Tier: Node.js Express server
Storage: Browser localStorage state.

Key Viva Answers

Cart Persistence: Retained via localStorage.setItem() and JSON.parse().
Cart Math: Computed via Array.prototype.reduce().
